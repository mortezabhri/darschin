PDF پیوست‌شده یک برگه انتخاب واحد دانشگاه است. اطلاعات همه درس‌های آن را استخراج کن و یک فایل JSON معتبر به نام `darschin.json` بساز.

مهم:
- فقط PDF منبع اطلاعات است.
- هیچ توضیح، گزارش، Markdown یا متن اضافه تولید نکن.
- اگر امکان ساخت/ارسال فایل داری، فقط فایل `darschin.json` را تحویل بده؛ در غیر این صورت فقط محتوای خام JSON را خروجی بده.
- همه درس‌های PDF باید استخراج شوند؛ هیچ درس را حذف نکن.
- برای هر درس دقیقاً یک object داخل `plans` قرار بده.
- ساختار، نام کلیدها و ترتیب کلیدها دقیقاً مطابق قالب زیر باشد.
- هیچ key جدیدی اضافه و هیچ key موجودی حذف یا تغییر نام داده نشود.
- مقدار `name` همیشه دقیقاً `"darschin"` باشد.
- اطلاعات را حدس نزن. اگر تاریخ یا ساعت امتحان در PDF مشخص نیست، مقدار آن را `"-"` قرار بده.

قالب خروجی دقیقاً:

{
  "name": "darschin",
  "plans": [
    {
      "lesson": "",
      "start": "",
      "end": "",
      "master": "",
      "description": "",
      "all_units": "",
      "exam_day": "",
      "exam_time": "",
      "day": 0,
      "hours": 0,
      "id": 0
    }
  ]
}

قواعد مقداردهی:

`lesson`
نام کامل درس مطابق PDF.

`start`
ساعت شروع کلاس به صورت رشته دو رقمی در قالب HH.
مثال:
08:00 → "08"
12:00 → "12"

`end`
ساعت پایان کلاس به صورت رشته دو رقمی در قالب HH.
مثال:
14:00 → "14"

`master`
نام استاد همان درس مطابق PDF.

`description`
فقط توضیح کوتاه محل برگزاری شامل شماره کلاس، طبقه و ساختمان/کارگاه.
اطلاعات اضافی مثل دانشکده، گروه درسی و کد درس را وارد نکن.
مثال:
"کلاس 1307 طبقه سوم ساختمان آموزشی- کارگاه کامپیوتر"

`all_units`
به ترتیب:
تعداد واحد تئوری-تعداد واحد عملی-تعداد کل واحد
بدون فاصله.
مثال:
"0-2-2"
"2-0-2"
"1-1-2"

`exam_day`
تاریخ امتحان شمسی دقیقاً در قالب YYYY/mm/dd.
مثال:
"1405/04/13"
اگر مشخص نشده:
"-"

`exam_time`
زمان شروع امتحان در قالب HH:mm.
مثال:
"10:00"
اگر مشخص نشده:
"-"
مدت امتحان را به جای ساعت شروع امتحان قرار نده.

`day`
روز برگزاری کلاس به عدد:
شنبه = 0
یکشنبه = 1
دوشنبه = 2
سه‌شنبه = 3
چهارشنبه = 4
پنجشنبه = 5
جمعه = 6

`hours`
مدت کلاس بر حسب ساعت و به صورت عدد.
مثال:
12 تا 14 → 2
15 تا 19 → 4

اگر یک درس در همان روز چند بازه زمانیِ پشت‌سرهم دارد، آن‌ها را یک کلاس محسوب کن:
start = شروع اولین بازه
end = پایان آخرین بازه
hours = مجموع مدت بازه‌ها

`id`
برای هر درس یک عدد صحیح یکتای 2 تا 6 رقمی تولید کن.
بازه مجاز: 10 تا 999999
هیچ دو object نباید id یکسان داشته باشند.

کنترل نهایی قبل از خروجی:
1. تعداد objectهای `plans` باید برابر تعداد درس‌های موجود در PDF باشد.
2. هر درس دقیقاً یک بار وجود داشته باشد.
3. تمام objectها دقیقاً 11 کلید بالا را داشته باشند.
4. ترتیب کلیدها دقیقاً مطابق template باشد.
5. JSON باید syntactically valid باشد.
6. trailing comma نداشته باشد.
7. فقط اطلاعات PDF استفاده شود.
8. خروجی نهایی فقط فایل/JSON باشد و هیچ توضیح دیگری نداشته باشد.

هیچ reasoning یا توضیح مراحل استخراج را در خروجی ننویس؛ مستقیماً JSON نهایی را تولید کن.
